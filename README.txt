VISTAAR — Data to Dashboard, Automatically
============================================

HOW TO USE
1. Open vistaar.html in any modern browser (double-click it, no install needed).
2. Upload your Excel/CSV/JSON file (drag-drop or click to browse).
3. If your file has multiple sheets, pick the right one from the dropdown on the review screen.
4. Confirm the auto-detected column types, then click "Build My Dashboard".
5. Use the type-pills to switch dashboard views, or let the tool auto-pick one.
6. Use the 🎨 Theme button (top-right) to switch between 5 color themes.
7. Export from the Export button: Excel / CSV / JSON / PDF / PNG.

WHAT'S NEW IN THIS VERSION
- Excel export is now a full dashboard workbook, not just raw data:
    • "Summary" sheet — report meta + every KPI card exactly as shown on screen
    • "Data" sheet — the full filtered dataset
    • One sheet per chart — its exact category labels and values
- Automatically drops stray, near-empty auto-named "Column N" placeholder columns
  left over from blank/merged Excel headers, so junk artifact columns no longer
  clutter your data table or exports.
- Smart auto-detection: picks Target & Collections or Profit & Loss view automatically.
- Cleans subtotal/grand-total rows and stray section-title rows from Excel exports.
- Multi-sheet Excel files: auto-picks the richest sheet, with a manual sheet switcher.
- Smarter category-column selection.
- 5 selectable, persistent color themes.

This is a single self-contained HTML file — no installation, no server, no data leaves your browser.
